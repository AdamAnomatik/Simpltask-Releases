# История изменений / Changelog

Все заметные изменения Simpltask публикуются в этом файле.

All notable Simpltask changes are documented in this file.

---

## [0.5.2] — 2026-08-03

### Русский

#### Добавлено

- Общий лимит видимых элементов: 4, 8 или 12.
- Значение по умолчанию — 8 элементов.
- Плавная пиксельная прокрутка в Launcher и Manager.
- Собственное тёмное меню значка в трее:
  - открыть Manager;
  - открыть настройки;
  - выйти.
- Промоблок SimplNote в установщике.

#### Изменено

- Launcher и Manager автоматически подстраивают высоту под выбранный лимит.
- Manager корректно растёт вверх и остаётся в рабочей области над панелью задач.
- Все восемь элементов полностью помещаются в Manager.
- Убраны стрелки справа от элементов Launcher.
- Настройка «Поверх всех окон» применяется только к Manager.
- Папки в Launcher отображаются зелёными значками, файлы — синими.
- В Manager используются углублённые зелёные и голубые подложки.
- Значки Launcher увеличены для лучшей читаемости.
- Убран ручной выбор цветов папок и файлов.
- Уточнены размеры и отступы компактного интерфейса.

#### Исправлено

- Позиционирование Manager рядом с панелью задач.
- Рост Manager за пределы рабочей области.
- Неполное отображение восьми элементов.
- Зазоры и переполнение красной области кнопки закрытия в настройках.
- Поведение окон при разных значениях DPI и масштаба Windows.
- Ряд проблем сборки и валидации релизного пакета.

#### Совместимость

- Пользовательские элементы и настройки сохраняются при обновлении.

### English

#### Added

- A shared visible-item limit of 4, 8, or 12.
- A default limit of 8 items.
- Smooth pixel scrolling in Launcher and Manager.
- A custom dark tray menu:
  - open Manager;
  - open Settings;
  - exit.
- A SimplNote promotional block in the installer.

#### Changed

- Launcher and Manager automatically adapt their height to the selected limit.
- Manager grows upward correctly and remains inside the working area above the taskbar.
- All eight items fit completely inside Manager.
- Item arrows were removed from Launcher.
- The always-on-top setting now applies to Manager only.
- Launcher uses green folder icons and blue file icons.
- Manager uses recessed green and blue icon plates.
- Launcher icons were enlarged for improved readability.
- Manual folder and file color selection was removed.
- Compact-interface dimensions and spacing were refined.

#### Fixed

- Manager positioning near the taskbar.
- Manager growth outside the working area.
- Incomplete display of eight items.
- Gaps and overflow in the red close-button hover area.
- Window behavior across different Windows DPI and display-scaling values.
- Several release build and validation problems.

#### Compatibility

- User items and settings are preserved during upgrades.
