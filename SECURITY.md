# Политика безопасности / Security Policy

## Поддерживаемые версии / Supported versions

| Версия / Version | Поддержка / Supported |
|---|---|
| 0.5.2 | Да / Yes |
| 0.5.1 и ниже / and earlier | Нет / No |

Пользователям рекомендуется устанавливать последнюю стабильную версию Simpltask.

Users are encouraged to install the latest stable Simpltask release.

## Русский

### Сообщение об уязвимости

Не публикуйте сведения об уязвимости в обычном GitHub Issue.

Предпочтительный способ:

1. Откройте вкладку **Security** официального репозитория.
2. Используйте **Report a vulnerability**, если функция доступна.
3. Приложите техническое описание и безопасные шаги воспроизведения.

Если приватная отправка недоступна, создайте краткое публичное обращение без технических подробностей и запросите приватный канал связи.

Укажите затронутую версию Simpltask, версию Windows, тип уязвимости, необходимые условия, безопасные шаги воспроизведения и возможное воздействие.

Не прикладывайте реальные пользовательские данные, секреты или вредоносные файлы.

Просим не публиковать технические детали до выхода исправления или согласования срока раскрытия.

## English

### Reporting a vulnerability

Do not publish vulnerability details in a normal GitHub Issue.

Preferred method:

1. Open the official repository’s **Security** tab.
2. Use **Report a vulnerability** when available.
3. Include a technical description and safe reproduction steps.

When private reporting is unavailable, open a brief public issue without technical details and request a private communication channel.

Include the affected Simpltask version, Windows version, vulnerability category, required conditions, safe reproduction steps, and potential impact.

Do not attach real user data, credentials, secrets, or harmful files.

Please avoid publishing technical details until a fix is released or a disclosure date is agreed upon.
