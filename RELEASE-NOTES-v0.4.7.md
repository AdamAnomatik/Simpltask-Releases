# Simpltask 0.4.7

Первый стабильный публичный релиз Simpltask.

## Возможности

- быстрый Launcher, открываемый с панели задач;
- поддержка нескольких мониторов;
- глобальная настраиваемая горячая клавиша;
- Simpltask Manager с добавлением файлов и папок перетаскиванием;
- внутренняя сортировка элементов;
- светлая, тёмная и системная темы;
- отдельная прозрачность фона Launcher, Manager и Settings от 0 до 100%;
- сохранение пользовательского списка и настроек между обновлениями;
- защита от повторного открытия второго Manager или второго окна Settings.

## Системные требования

- 64-разрядная Windows.

## Обновление

Установщик можно запускать поверх предыдущей версии. Список элементов и пользовательские настройки сохраняются.

## Проверка файла

Вместе с установщиком опубликован файл SHA-256. Его можно использовать для проверки целостности загрузки.
