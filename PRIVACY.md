# Политика конфиденциальности / Privacy Policy

**Дата вступления в силу / Effective date:** 3 August 2026  
**Приложение / Application:** Simpltask

---

## Русский

Simpltask — локальное приложение для быстрого доступа к файлам, папкам и программам в Windows. Приложение не требует учётной записи и не предоставляет облачную синхронизацию.

### Какие данные хранятся локально

Для работы Simpltask может хранить на компьютере пользователя:

- список добавленных файлов, папок и приложений;
- пути к этим элементам;
- пользовательские названия;
- параметры интерфейса и темы;
- настройки поведения, положения и размеров окон;
- другие локальные настройки, необходимые для работы приложения.

Эти данные используются только для отображения и запуска выбранных пользователем элементов.

### Передача данных

В текущей версии Simpltask не передаёт разработчику список добавленных элементов, пути, содержимое файлов, настройки или телеметрию использования.

Simpltask не использует рекламные SDK и не продаёт пользовательские данные.

### Внешние ссылки

Приложение или установщик могут содержать ссылки на официальные страницы Simpltask, SimplNote, GitHub и связанные ресурсы. Внешняя страница открывается только после действия пользователя. После перехода применяются правила соответствующего сайта и браузера.

### Хранение и удаление

Данные Simpltask хранятся локально в профиле Windows пользователя. Пользователь может удалить их через доступные действия приложения либо вручную после удаления Simpltask.

### Доступ к файлам

Simpltask хранит ссылки на выбранные пользователем файлы, папки и приложения, чтобы запускать их по команде пользователя. Содержимое этих файлов не загружается на сервер разработчика.

### Изменения политики

Политика может обновляться при появлении новых функций, включая сетевые сервисы, проверку обновлений или диагностическую телеметрию.

Вопросы можно направлять через [GitHub Issues](https://github.com/AdamAnomatik/Simpltask-Releases/issues). Не публикуйте персональные данные, приватные пути, секреты или конфиденциальные файлы.

## English

Simpltask is a local Windows application for quick access to files, folders, and programs. It does not require an account and does not provide cloud synchronization.

### Data stored locally

Simpltask may store the following information on the user’s computer:

- the list of added files, folders, and applications;
- paths to those items;
- custom item names;
- interface and theme preferences;
- window behavior, position, and size settings;
- other local settings required by the application.

This information is used only to display and launch items selected by the user.

### Data transmission

The current version of Simpltask does not send the developer the user’s item list, paths, file contents, settings, or usage telemetry.

Simpltask does not include advertising SDKs and does not sell user data.

### External links

The application or installer may contain links to official Simpltask, SimplNote, GitHub, and related pages. An external page opens only after a user action. The destination website and browser policies then apply.

### Storage and deletion

Simpltask data is stored locally in the user’s Windows profile. Users may remove it through available application actions or manually after uninstalling Simpltask.

### File access

Simpltask stores references to user-selected files, folders, and applications so it can launch them on request. Their contents are not uploaded to the developer’s server.

### Policy changes

This policy may be updated if new functionality is introduced, including network services, update checks, or diagnostic telemetry.

Questions may be submitted through [GitHub Issues](https://github.com/AdamAnomatik/Simpltask-Releases/issues). Do not publish personal data, private paths, credentials, secrets, or confidential files.
