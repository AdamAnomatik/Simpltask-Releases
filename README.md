# Simpltask

Simpltask — компактная Windows-утилита быстрого доступа к часто используемым файлам и папкам.

Исходный код приложения закрыт. Этот публичный репозиторий предназначен для официальных установщиков, описаний версий и сообщений об ошибках.

## Скачать

Откройте раздел **Releases** и скачайте последний установщик:

`Simpltask-Setup-x.y.z.exe`

Рядом с ним публикуется файл контрольной суммы:

`Simpltask-Setup-x.y.z.sha256.txt`

## Основные возможности

- Launcher с панели задач;
- работа на нескольких мониторах;
- настраиваемая глобальная горячая клавиша;
- Manager с drag-and-drop;
- светлая, тёмная и системная темы;
- прозрачность фона от 0 до 100%;
- сохранение настроек при обновлении.

## Данные пользователя

Настройки и список элементов хранятся в:

`%LOCALAPPDATA%\Simpltask`

При обычном обновлении и удалении приложения они сохраняются.
